Question 6

Let \(y(x)\) be the solution to the following initial value problem.

\[y^2\,dx-\sec^2(9x)\,dy=0,\qquad y(0)=8.\]

Find \(y(\pi)\).

Show answer

Childsmath’s recorded answer is \(8/(1-4\pi)\), but this is not a value of the solution of the IVP. There is no value \(y(\pi)\) for that solution.

Near \(x=0\), separation gives

\[y(x)=\frac{8}{1-4x-\frac{2}{9}\sin(18x)}.\]

Substituting \(x=\pi\) in this expression gives the recorded answer. However, the original equation contains \(\sec^2(9x)\), which is undefined at \(x=\pi/18\). Thus its solution interval containing \(0\) cannot reach \(\pi\). Even if we extend the equation as \(y'=y^2\cos^2(9x)\), the displayed solution becomes unbounded before \(x=\pi\): its denominator is positive at \(\pi/18\) and negative at \(\pi/9\), so it must vanish between them.
